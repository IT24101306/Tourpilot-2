How It Works

Use this tab to understand the flow from package selection to referral sharing and commission tracking.

1. Pick a package

Select any package from the agency list. The dashboard uses the same package set, so the referral details match what travelers see.

2. Generate a referral code

Use the builder or the package card button to create a unique code for the selected package.

3. Share and track commission

The commission estimate updates based on the package price and the rate you choose on the dashboard.

4. Reuse saved codes

Saved codes stay in your browser so you can copy them again without rebuilding them every time.
